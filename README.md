# AI Customer Churn Intelligence System

## Overview
An AI-powered decision intelligence system that predicts customer churn,
explains risk drivers, estimates revenue exposure, and recommends retention actions.

## Features
- Machine Learning churn prediction
- Explainable AI (XAI)
- Revenue risk estimation
- AI retention recommendations
- Interactive Streamlit dashboard

## Tech Stack
Python, Scikit-learn, Streamlit, Pandas

## Run Project

Train model:
python churn_model.py

Launch dashboard:
streamlit run app.py
